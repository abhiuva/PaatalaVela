## Live Catalogue Baseline

The linked Supabase project returned seven active channels, 94 songs, 105 channel assignments, and 1,587 listening events at audit time. English Hits is present with UUID `6f3fc628-a517-4dc5-a479-334d6bce7558`. No Phase 1 code or content mutation was performed before this audit was written.

The data-quality pass must treat release years and film values as reviewable because several records appear to use YouTube publication metadata instead of the original song release metadata. Incomplete or questionable metadata is not a deletion criterion.
